pipeline

How a link becomes a capability

  1. 01

    Recon

    Read the repo before running it: which tree actually holds the skills, what the installer expects, which toolchains this machine even has. A missing compiler is a fact, not a failure.

    read · classify · decide
  2. 02

    Install & verify

    Prefer the registry over a source build, then make the tool prove itself with a real command. Record its actual output — a version string that errors means it is not installed.

    npm · uv · pip · cargo-free
  3. 03

    Forge skills

    Copy canonical skill trees into the agent library, repair the frontmatter agents need, collapse duplicate names, then validate every file in one pass. Nothing is claimed that the disk cannot show.

    copy · normalise · validate
